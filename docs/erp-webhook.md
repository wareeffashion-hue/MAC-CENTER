# ربط النظام المحاسبي بموقع ماك سنتر (MAC+)

هذا المستند لمزود النظام المحاسبي. المطلوب أن يرسل النظام كل فاتورة بيع أو مرتجع إلى موقع ماك سنتر فور إصدارها.

## العنوان

```
POST https://maccenter.com.sa/api/webhooks/erp
Content-Type: application/json
X-Api-Key: <المفتاح السري>
```

يسلمكم فريق ماك سنتر المفتاح السري بقناة آمنة. ويمكن بدل `X-Api-Key` إرسال توقيع لجسم الطلب:
`X-Signature: sha256=<HMAC-SHA256(body, secret) بصيغة hex>`.

## فاتورة واحدة

```json
{
  "invoice_no": "INV-10045",
  "branch_code": "01",
  "date": "2026-10-19T14:22:00+03:00",
  "type": "sale",
  "total": 480.50,
  "customer_phone": "0551234567",
  "member_code": "888MC3",
  "invoice_url": "https://.../INV-10045.pdf",
  "items": [
    { "name": "فستان بناتي", "category": "فساتين المناسبات", "qty": 1, "price": 180 },
    { "name": "حذاء", "category": "الأحذية والحقائب", "qty": 1, "price": 90 }
  ]
}
```

| الحقل | إلزامي | الوصف |
|---|---|---|
| `invoice_no` | نعم | رقم الفاتورة، فريد داخل الفرع |
| `branch_code` | نعم | رمز الفرع أو نقطة البيع في النظام المحاسبي |
| `total` | نعم | صافي الفاتورة المدفوع شاملًا الضريبة |
| `date` | لا | وقت الإصدار ISO 8601. الافتراضي وقت الاستلام |
| `type` | لا | `sale` (الافتراضي) أو `return` للمرتجع |
| `original_invoice_no` | للمرتجع | رقم فاتورة البيع الأصلية |
| `customer_phone` | لا | جوال العميل إن سُجل في الفاتورة |
| `member_code` | لا | رقم عضوية MAC+ (يمسحه الكاشير من بطاقة العميل) |
| `items[].category` | مستحسن | تصنيف الصنف أو مجموعته، يُربط بأقسام ماك سنتر من لوحة التحكم |
| `invoice_url` | لا | رابط الفاتورة الإلكترونية (https) يُرسل للعضو في إيصال واتساب |

يُقبل أيضًا إرسال عدة فواتير معًا: `{ "invoices": [ ... ] }` بحد 500 فاتورة في الطلب.
وتُقبل أسماء بديلة شائعة للحقول، مثل `invoiceNo` و`branchCode` و`grand_total` و`mobile`.

## الرد

```json
{ "ok": true, "results": [ { "invoice_no": "INV-10045", "status": "member" } ] }
```

| الحالة | المعنى |
|---|---|
| `member` | فاتورة عضو MAC+: حُسبت خطوط العربة وأُضيفت المكافأة رصيدًا ووصله إيصال واتساب |
| `guest` | عميل غير عضو: تدخل في أرقام الفرع اليومية فقط |
| `return` | مرتجع: سُحب ما لم يُستخدم من مكافأة الفاتورة الأصلية |
| `unmapped` | رمز الفرع أو التصنيفات غير مربوطة بعد. تُعاد معالجتها تلقائيًا بعد ربطها في اللوحة |
| `duplicate` | الفاتورة وصلت من قبل. إعادة الإرسال آمنة |
| `invalid` | حقل إلزامي ناقص |

أي رد غير 200 (مثل 401 أو 429 أو 5xx) يعني إعادة المحاولة لاحقًا. والإرسال المكرر لا يسجل الفاتورة مرتين.

## مثال

```bash
curl -X POST https://maccenter.com.sa/api/webhooks/erp \
  -H "Content-Type: application/json" -H "X-Api-Key: $SECRET" \
  -d '{"invoice_no":"T-1","branch_code":"01","total":120,"items":[{"name":"قميص","category":"أزياء"}]}'
```
