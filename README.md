# ماك سنتر: الموقع ولوحة الإدارة

<img src="public/img/logo-horizontal.svg" alt="ماك سنتر MAC CENTER" height="64">

موقع عربي لماك سنتر ومجمع عادل الدولي (فرعا الدائري وقباء) في المدينة المنورة، مع لوحة إدارة كاملة تشمل:

- الاشتراك في العروض عبر واتساب
- إدارة العروض والحملات
- الشكاوى والملاحظات وتذاكر المتابعة
- تقييمات Google Business Profile والرد عليها
- رموز QR داخل الفروع

![صورة المشاركة](public/og.png)

## التشغيل السريع

يحتاج Node.js 22.13 أو أحدث، ولا يعتمد على أي حزمة خارجية.

```bash
cp .env.example .env              # عدّل القيم
npm run create-admin -- admin@maccenter.com.sa "كلمة-مرور-قوية"
npm start                         # http://localhost:3000
```

- **الموقع:** `http://localhost:3000`
- **لوحة الإدارة:** `http://localhost:3000/admin`

### تجربة كاملة ببيانات وهمية

```bash
DATA_DIR=./data-demo npm run seed:demo
DATA_DIR=./data-demo npm start
```

ادخل بـ `admin@demo.sa` / `Demo12345!`. وتوجد حسابات بأدوار مختلفة بكلمة المرور نفسها: `quba.manager@demo.sa` و`agent1@demo.sa` و`marketing@demo.sa` و`reviewer@demo.sa`.

في وضع التجربة (`WHATSAPP_DRIVER=mock` و`GOOGLE_DRIVER=mock`) لا تغادر أي رسالة النظام. ومن صفحة «الربط» في اللوحة تستطيع:

- محاكاة رسائل واتساب الواردة
- عرض الرسائل الصادرة
- إضافة تقييمات Google تجريبية تمر بقواعد الرد نفسها

### الاختبارات

```bash
npm test
```

46 اختبارًا تغطي:

- **الدوام:** الفترات المتعددة، والإغلاق بعد منتصف الليل، واستثناءات رمضان والأعياد.
- **الاشتراك:** رحلته كاملة، ومنع التكرار، والإيقاف الفوري.
- **الحملات:** السقف الأسبوعي، وساعات الإرسال، والإلغاء أثناء الإرسال.
- **التذاكر:** التوجيه والتصعيد وصلاحيات الفروع.
- **التقييمات:** التصنيف، ومنع الرد المكرر، وعدم استبدال الرد البشري.
- **الأمان:** حماية المرفقات، ورفض الطلبات من مواقع أخرى.

## الموقع العام

| الصفحة | ما فيها |
|---|---|
| `/` | البطل بنوافذ الأقسام والمسار الأصفر، والتعريف، والأقسام (لوحة لكل قسم فيها الفروع والاستفسار)، والعروض، والفروع (تبويبات مع مفتوح أو مغلق الآن)، والخدمات، والتقييمات المختارة، والأسئلة |
| `/branches/:slug` | صفحة مستقلة لكل فرع فيها: الدوام الأسبوعي والاستثناءات، والخريطة عند الطلب، والأقسام مع استفسار واتساب لكل قسم، والخدمات، ورابط التقييم |
| `/offers` و`/offers/:slug` | العروض السارية، ولكل عرض رابط مستقل قابل للمشاركة |
| `/subscribe` | اختيار الفروع والأقسام وأخذ الموافقة، ثم رسالة واتساب جاهزة برمز ربط مؤقت |
| `/subscribe/status/:key` | انتظار التأكيد. لا تظهر حالة «مكتمل» إلا بعد وصول رسالة العميل فعلًا |
| `/preferences/:token` | تعديل الاهتمامات أو إيقاف فرع أو قسم أو كل الرسائل |
| `/feedback` | شكوى أو مقترح أو تقييم أو طلب تواصل، مع حتى 3 صور. رابط Google يظهر للجميع بالوضوح نفسه |
| `/track/:key` | تتبع الملاحظة. التفاصيل لا تظهر إلا بعد إدخال آخر 4 أرقام من الجوال |
| `/q/:code` | رابط QR المطبوع: ثابت، ووجهته قابلة للتغيير من اللوحة |

### الهوية والحركة

- **الألوان والخط:** ألوان ملف الشعار، وخط Gamila Arabic.
- **الاتجاه البصري «نوافذ ماك»:** نوافذ هندسية لكل قسم، يربطها مسار أصفر مستلهم من خطوط عربة الشعار، وتنتهي عند العربة نفسها.
- **الصور:** لكل قسم رسم تجريدي يبقى بديلًا حتى ترفع الصور الحقيقية من اللوحة.
- **حركة الافتتاح:** CSS فقط، فتبدأ مع أول رسم دون انتظار JavaScript.
- **العربة على الشاشات العريضة:** تتقدم على مسار جانبي مع التمرير.
- **احترام تقليل الحركة:** خيار «تقليل الحركة» يعطّل الانتقالات المكانية.
- **السرعة:** الصفحة الرئيسية نحو 17 كيلوبايت مضغوطة، والخطوط محملة مسبقًا، والخريطة لا تحمل إلا عند الطلب.

## لوحة الإدارة

- **اليوم:** التذاكر الجديدة والمتأخرة، والتقييمات التي تحتاج ردًا، والحملات القادمة، وحالة الربط، ونشاط 14 يومًا.
- **التذاكر:**
  - المرشحات والبحث.
  - الاستلام والإسناد والحالة والأولوية، وتصحيح التصنيف.
  - ملاحظات داخلية، وتوثيق التواصل مع العميل.
  - المرفقات بروابط صالحة 5 دقائق.
- **تقييمات Google:**
  - درجة كل فرع مستقلة.
  - المسودات والنشر.
  - تعليمات الرد لكل فرع، مع اختبار القواعد على أمثلة.
  - الرد التلقائي لا يفعّل إلا بموافقة صريحة مسجلة.
- **العروض والحملات:**
  - دورة العرض: مسودة، ثم مراجعة، ثم اعتماد، ثم مجدول أو نشط أو منتهٍ أو ملغى.
  - حجم الجمهور المؤهل والتكلفة التقديرية.
  - رسالة اختبار إلزامية قبل الجدولة.
  - إيقاف مؤقت وإلغاء.
  - إعادة محاولة الرسائل الفاشلة.
- **المشتركون:** تصفية بالفرع والقسم والحالة، وسجل الموافقة، والتصدير للمخولين فقط.
- **رموز QR:** لكل فرع وموقع داخله، مع عدد المسح والاشتراكات المؤكدة، وتصدير SVG وPNG.
- **الفروع والدوام:**
  - دوام متعدد الفترات، واستثناءات المواسم.
  - الأقسام والخدمات لكل فرع.
  - إضافة فرع رابع دون تعديل الكود.
- **المحتوى:** الأقسام وصورها، والأسئلة المتكررة، ونصوص الموقع.
- **الفريق والتوجيه:** خمسة أدوار، وجدول توجيه بمسؤول وبديل.
- **التقارير:** رحلة الاشتراك، والاهتمامات، ونتائج الحملات، وأزمنة الخدمة، والملاحظات المتكررة.
- **الربط، وسجل التدقيق، والإعدادات، وحسابي:** يشمل «حسابي» التحقق الثنائي عبر تطبيق المصادقة.

### الأدوار

| الدور | يرى ويعدل |
|---|---|
| مدير النظام | كل شيء |
| مدير الفرع | تذاكر فرعه، والإسناد، ودوام فرعه ومحتواه، والتقييمات، والتقارير |
| موظف خدمة العملاء | التذاكر المسندة إليه وطابور فرعه |
| مسؤول التسويق | العروض والحملات والمشتركون ورموز QR والتقارير |
| مراجع الردود | تقييمات Google في الفروع المخولة |

## البنية

```
src/
  server.js          الخادم والتوجيه وحماية الطلبات
  db.js              قاعدة SQLite المدمجة في Node وترحيلاتها
  jobs.js            المهام المجدولة: الحملات، والتصعيد، ومزامنة التقييمات، والتنظيف
  lib/               الدوام بتوقيت الرياض، ومولد QR، والتحقق الثنائي، والمعرفات
  modules/           منطق كل مجال: الفروع، والعروض، وواتساب، والتذاكر، والتقييمات، والتقارير…
  routes/            المسارات العامة وواجهة اللوحة
  views/             صفحات الموقع (تولد في الخادم لتكون قابلة للفهرسة)
public/
  css/ js/           واجهة الموقع (تحسين تدريجي: كل شيء يعمل دون JavaScript)
  admin/             لوحة الإدارة (وحدات JavaScript تحمل عند الحاجة)
```

### إضافة شاشة جديدة للوحة

1. أنشئ `public/admin/js/views/name.js` يصدّر `render(view, ctx)`.
2. أضف سطرًا في `ROUTES` داخل `public/admin/js/app.js`.
3. أضف مسارات الخادم في `src/routes/api.js`، واحمها بـ `auth('permission')`.

### إضافة جدول أو عمود

أضف عنصرًا جديدًا في نهاية مصفوفة `SCHEMA` في `src/db.js`. الترحيلات تطبق تلقائيًا عند التشغيل.
